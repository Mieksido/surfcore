# v0.8.4 Linux/POSIX 投稿验收

基线：官方 main bbec1461（v0.8.4）。仅本地投稿分支，未发布。

## 完整逻辑

链路：设置页调用宿主桥接启动/停止及本地 URL 打开，更新服务下载/解压后由独立助手复制。
机制：按平台选择命令；Linux 核对 /proc 中 PID、UID、脚本、可执行文件、工作目录及启动时间；POSIX 使用 HOME 和 0700 新目录。
影响：只影响平台适配及测试夹具；Windows 分支保留；已有目录不自动 chmod。ZIP 更新不删除目标额外文件，保护配置/状态，拒绝源和目标链接。
取舍：不模拟 Windows 命令，不跳过通用断言；使用平台实现和无副作用夹具验证。
生效：重启 DSH 加载宿主修改，更新助手在宿主退出后运行。
验证：npm run test:audit；插件 npm test；npm run test:regressions；node --check；正式 HEAD 清单和归档核对。最终数字见投稿证据。
回滚：仅撤回本 PR，不修改用户数据或原验收分支。PID 校验与信号发送间仍有竞态；macOS 停止和 Windows 真机不在已验证范围。

## 发布交接块

改动：Linux/POSIX 平台实现及夹具兼容。
版本：保持 0.8.4，不 bump/tag/push。
层级：实现与测试，接口兼容；失败路径保留可行动错误。
测试：最终 HEAD 日志和脱敏证据记录实际结果，不沿用旧 94/94。
限制：Windows 真机未验证；Debian 旧版证据与本轮验证范围分别说明。
