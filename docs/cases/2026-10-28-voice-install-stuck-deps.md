# 2026-10-28 · 语音包卡在「安装 Python 依赖 99%」50 分钟，且没法取消

## 现象

- 用户点安装后，卡片显示「安装 Python 依赖（首次 5~40 分钟） 99%」，进度条一直滚动；
- 等了 50 分钟没有变化，也不知道还要多久；
- 前端文案变成「⚠️ 安装还没完成（可重试）」，但后端其实还在装；
- **没有取消入口**，只能卸载重来。

## 根因

1. **这一阶段没有百分比**：pip 安装依赖（`torch` 等）没有稳定进度输出，
   `rec.progress` 停在 99，前端只能显示不确定态；
2. **不显示"在装什么 / 装多久"**：用户看到 99% 却没有任何信息判断是慢还是卡；
3. **pip 默认走 pypi 官方源**：国内经常几十 KB/s，装 200MB+ 的 torch 会非常久（报告里也提过 #11）；
4. **没有取消**：`activeInstalls` 里的子进程没有句柄暴露，前端想取消也做不到；
5. 前端 `poll()` 6 分钟超时后写「安装还没完成（可重试）」，容易被理解成失败。

## 修法（v0.6.21）

| 改动 | 说明 |
| --- | --- |
| 显示耗时 + 最近动作 | 进度条阶段名变成 `安装 Python 依赖 · 已 12 分钟 · 最近：Downloading torch…` |
| 阶段名细化 | 解析 `[bootstrap] …` 输出，显示"装 voxd 依赖 / 装 GPT-SoVITS 依赖"等真实步骤 |
| **取消安装** | 新增 `cancelInstall(id)` + `/api/voice/packs/cancel`，杀子进程树并标记失败；UI 在安装中显示「取消安装」 |
| pip 默认清华源 | `SURFCORE_PIP_INDEX` 可覆盖；失败再依次回退阿里源、官方源 |
| pip 输出可读 | `--progress-bar off --timeout 30 --retries 5`，按包名逐行输出（宿主能显示"最近在装什么"） |
| 文案不吓人 | 超时后改「⏳ 还在安装（依赖阶段可能要几十分钟）；卡住可以点取消安装」 |

## 验证

- `npm run test:audit` 77/77；插件测试 0 失败；
- **未验证**：真实机器上装 torch 的耗时改善（需要一台干净 Windows + 国内网络），
  以及「取消安装」是否把 python/pip 子进程树杀干净。

## 遗留

- torch 本身 200MB+，CPU 版也躲不掉；首次安装仍是"几分钟到几十分钟"的量级；
- 可以在 bootstrap 里再加一层"已装依赖就跳过"（pip 本来会跳过，但解析 requirements 仍耗时）;
- 取消后要不要清理半截 venv，暂不处理（保留能续装）。
