# 设置页保存按钮太阴间 / 点了没效果

日期：2026-11-02

## 1. 现象

- 保存按钮和底栏背景太接近，看不清；
- 群管理里改了设置，点页面底部「保存」没效果；
- 保存成功提示只出现在底栏，长页面看不到；
- 用户不知道群管理/管理员还有自己的保存入口。

## 2. 根因

- 全局「保存」只写配置，不重启 QQ 桥接；QQ 侧设置要重启才生效；
- 「保存」和「保存并重启 QQ 桥接」并列，主次不清；
- 群管理是独立 `/group-policy` 保存，全局脏状态不算它；
- 群管理弹窗保存按钮在滚动内容底部，弹窗底部只有「取消」；
- 管理员卡片没有局部保存；
- `.qbw-btn2` 透明底 + 淡边框，底栏背景也接近；
- 成功提示只渲染在底栏文本里。

## 3. 修法

- 全局主按钮改成「保存并生效」（保存 + 重启 QQ 桥接），次按钮「仅保存（不重启）」；
- 保存成功提示改成固定 `.qbw-toast`，不再只显示在底栏；
- `.qbw-app` 改成 flex 列布局，底栏固定可见；
- `.qbw-btn2` 改成实底 + 明确边框，主按钮加粗；禁用透明度 .55→.68；
- `SettingsModal` 改成 flex：内容滚动、底部保存栏固定；
- 群管理弹窗通过 `onSaveReady` 把保存函数注册到弹窗底部，底部固定「保存」；
- 管理员卡片加「保存管理员并重启桥接」局部按钮；
- 客户端契约测试增加保存 UX 断言。

## 4. 生效/风险

- 重启 DSH / 重新加载插件后生效；
- 「保存并生效」会重启 QQ 桥接，可能打断正在进行的回合；
- 「仅保存」保留给不想重启的人，但 QQ 侧仍要下次重启才生效；
- 群管理保存和全局保存仍是两个端点，但弹窗底部现在明确；
- 固定 toast 可能遮挡底部少量内容，已限制最大宽度并 pointer-events:none；
- 没有真实浏览器截图回归，使用源码契约测试。
