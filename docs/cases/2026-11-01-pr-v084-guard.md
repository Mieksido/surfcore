基线：官方 main bbec1461（v0.8.4）。仅本地投稿分支，未发布。

## 完整逻辑

链路：Preset 内 qq-tool-restrict → scoped tools.restrict/guard；tools/change 到达后补装此前 unknown 的限制。
机制：成功限制只安装一次，在 restrict 发事件前登记名字以防同步重入；执行白名单始终保留。
影响：只有 QQ Preset scope；不修改普通 Agent，也不引入 Linux 功能依赖。
取舍：采用事件重试，不改全局工具注册顺序，不用模拟调度器冒充集成；单元测试只验证 API 契约，真实 DSH 使用独立插件夹具。
生效：重启 DSH。
验证：node scripts/test-qq-tool-restrict-events.mjs；真实宿主加载 scripts/fixtures/qq-guard-dsh-acceptance.mjs 并设置 SURFCORE_GUARD_RESULT，必须在临时隔离 Profile 中执行；工具体只有计数器，无模型/QQ 调用。
回滚：撤回本 PR 即恢复旧 Guard。非静态名单内的新工具不承诺 Schema 隐藏，但执行白名单仍拒绝。

既有 v0.8.0 控制组为 101/107；本次将实际运行 v0.8.4 控制组核对失败项，不把旧结果当新版结果。没有修改或跳过它们来得到全绿。正式本分支结果与日志见投稿证据。
