# 2026-11-09 关系底层改造：平等相处，不做主仆/情侣

## 1. 现象（用户要求）

用户明确：要和她**平等相待**，不是情侣/主仆；且不要靠写一句「我们是平等的」实现，要从底层改；其他同类地方一起改。

## 2. 根因（底层预设）

| 位置 | 原来的预设 |
| --- | --- |
| `persona-identity.js` | 身份句写「**你的主人是 X**」（默认占位「主人」） |
| `admin-identity.js` | 「主人·温柔模式（优先级高于人格卡）」：**绝不回嘴、先认错、撒娇、乖乖照做、更黏更乖** |
| `purpose-engine.js` | 目标全是「**跟主人**说说/问问主人/想和主人一起」；连接驱动按「多久没和主人说话」上涨；线索词含「撒娇/想主人/缺爱」 |
| `bili-memory.js` | 默认称呼「主人」，脱敏替换也写「主人」 |
| 插件 `index.js` / 设置页 `client.js` / 记忆卡 / 问答标签 / 提示工具 | 大量「主人」称呼与「和主人的初次相遇」等标题 |
| 人格文案层 | 黏人、思念、撒娇、被冷落闹情绪、叫「笨蛋」等情侣/依赖化设定 |

## 3. 修法

1. **身份句**：`你是X；对方叫Y（没有就说“对方是你认识的人”）。你们是熟人，朋友式相处。` ——不写主人/情侣，也不写「平等」口号。
2. **管理员块**：只描述**权限事实**（谁能审批/发命令/带【管理员】标记），语气照人格卡；明确「不用讨好、不用撒娇、不用认错」「管理员身份不改变人格与边界」。marker 从【管理员·温柔】改为【管理员】。保留 gentle 开关作为「是否注入权限块」。
3. **目的机制**：所有「主人」→「对方」；动作文案「跟对方说说/问问对方」；**删除「对方多久没说话 → 连接需求上涨」的依赖驱动**；线索词去掉「撒娇/想主人/缺爱」；关系类目标不再生成「我们算什么关系」，改为近况关心。
4. **称呼/文案统一**：`bili-memory` 默认「你」，脱敏替换「对方」；记忆卡标题「和对方」；问答来源标签「管理员/非管理员」；设置页「主人」全部改为「你/管理员」；允许列表提示改「管理员」。
5. **让她知道用户名字**：管理员 `displayName` 写入用户 QQ 昵称，身份句变成「对方叫 非人叙事者」——只作为**事实**，不设定称呼。
6. 人格文案（core/tone/daily/scenes）另出**平等版**给用户手动粘贴，不自动改动角色卡。

## 4. 影响面

- 注入提示词：身份句、管理员块（仅在 gentle 开启时）、目的机制 prompt、记忆卡标题、问答来源标签。
- 所有平台（QQ/群/私聊/B站/桌宠）共用。
- 不碰用户数据、密钥；不改协议常量 `[仅主人]`（避免 preset 不兼容），只改展示文案。

`git revert`；或把 admin `displayName` 清空、恢复旧 persona 文件备份。
